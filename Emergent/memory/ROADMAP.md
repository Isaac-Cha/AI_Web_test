# Emergent 网站后续完善计划

目标：围绕“无限量化（MetaTrader）”面向外汇交易者的品牌站，提供合作平台信息、EA/指标展示、教学外链与加入合作线索收集，并保持三套视觉模式同步迭代。

## 0.工程现状速览

- 前端：`frontend/`（React + react-router-dom），三种界面模式路由：`/`（Sci‑Fi）、`/apple`、`/hybrid`。
- 后端：`backend/`（Python），提供 API（EA/指标/教学/关于等内容可逐步由 API 驱动）。
- 三模式同步原则：
  - 内容一致（同一份数据源、同一套字段与排序）
  - 交互一致（同一套表单、弹窗、二维码浮窗逻辑）
  - 视觉允许差异（排版/色板/动效强度可不同，但模块边界一致）

## 1.第一阶段（可上线 MVP）

### 1.1 页面与信息结构（所有模式一致）

- 合作平台：理念/活动/规则/Q&A（从后端或静态配置读取）
- EA：列表 + 详情（收益/风险/策略/合作条件）
- 指标：列表 + 解释（分类/术语）
- 教学：百度网盘链接 + 标签
- 加入我们：表单 + 微信二维码

### 1.2 数据与后台（优先级高）

- 定义统一的数据模型：Platform / EA / Indicator / Tutorial / JoinLead
- 后端 API：列表分页、详情、搜索、语言字段
- 简单的“内容管理入口”：
  - 方案 A：先用 JSON 文件（最快上线）
  - 方案 B：接入 Supabase（后续可替换后端部分）

### 1.3 SEO 与投放

- 每页 Title/Description/H1 固化模板 + 可后台配置
- 关键词落地（黄金/外汇/量化/自动交易/MT4/MT5/EA/XAUUSD/COMEX 等）
- 结构化数据（FAQPage / Organization）

## 2.第二阶段（体验与转化）

- 3D 视差与卡片动效（EA/指标列表）：统一的弹簧阻尼参数，模式内风格可微调
- 自定义鼠标与轨迹：提供开关（移动端自动降级）
- 表单反垃圾：同设备/同 IP 短时间提交频控 + 服务端限流（JoinLead 写入）
- 本地缓存：对平台/配置/列表做缓存（降低 API 压力、提升首屏速度）

## 3.第三阶段（可维护性与规模化）

- 抽象“模式主题层”：
  - 统一组件库 + 主题 token（颜色/阴影/玻璃强度/动效强度）
  - 三模式只改 token 与布局组合
- 代码结构治理：
  - 公共内容模块与模式 UI 分离
  - 所有模式共用同一数据 hook（请求/缓存/错误处理）
- CI/CD：构建检查、前端产物部署、后端健康检查

## 4.交付节奏建议

- 先把“合作平台页”做成最完整的样板（含 Q&A + 二维码 + 文案结构）
- 再按 EA → 指标 → 教学 → 加入我们逐页完善
